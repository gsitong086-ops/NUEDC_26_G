================================================================================
  AD9226 并行ADC采集与信号分析系统 — 软件框架设计思路
  平台: STM32F407ZGT6 (Cortex-M4, 168MHz)
  工具链: Keil MDK-ARM (ARMCLANG V6.16)
  DSP库: CMSIS-DSP (arm_cortexM4lf_math.lib)

一、硬件资源分配
────────────────────────────────────────────────────────────────
  资源              用途
  ──────────────────────────────────────────────────────────
  GPIOD[0:11]       读取 AD9226 12位并行数据 (输入)
  TIM8 CH1          输出 PWM 作为 ADC 采样时钟 (~4MHz)
  TIM8 UPDATE       触发 DMA2_Stream1 搬运 GPIOD->IDR
  DMA2_Stream1      自动搬运 8192 个采样点到 adc_buffer
  PE5/PE6           驱动继电器: LOW=直通, HIGH=LPF通路
  USART1            与淘晶驰串口屏通信 (115200bps)
  HSE 8MHz → PLL   SYSCLK=168MHz, APB2=84MHz

四、数字 FIR 滤波器设计 (digital_filter.c)
────────────────────────────────────────────────────────────────
  类型:       64-tap 线性相位 FIR 低通滤波器
  窗函数:     Kaiser 窗 (β = 7.85726)
  输入采样率: 4 MSPS
  输出采样率: 2 MSPS (2:1 抽取)
  截止频率:   750 kHz
  通带特性:   500kHz 处衰减约 0.001 dB
  阻带衰减:   -82.6 dB @ 1 MHz
  系数归一化: 单位 DC 增益

  实现细节:
  - 使用环形缓冲区 state[64] 存储最近的 64 个采样点
  - 每个采样点先减去 2048 (去直流), 再做卷积
  - 仅对偶数索引 (n & 1 != 0) 输出结果 (2:1 抽取)
  - 卷积结果加回 2048 并限幅到 [0, 4095]

  为什么需要 2:1 抽取:
  - 滤除 >750kHz 的高频噪声后, 信号带宽减半
  - 根据奈奎斯特定理, 2MSPS 足够覆盖 0~1MHz 的分析范围
  - 输出点数 4096, 直接匹配 FFT 输入点数


五、FFT 频谱分析 (fft_analysis.c)
────────────────────────────────────────────────────────────────
  5.1 FFT 参数
  ──────────────────────────────────────────────────────────
    FFT 点数:         4096
    等效采样率:       2 MSPS
    频率分辨率 (bin): ~488 Hz
    分析频率范围:     9 kHz ~ 550 kHz (DC 和低频噪声跳过)
    窗函数:           Hann 窗 (0.5 - 0.5*cos(2π*n/(N-1)))
    FFT 实现:         CMSIS-DSP arm_rfft_fast_f32 (实数FFT)

  5.2 基波检测
  ──────────────────────────────────────────────────────────
    1. 在有效频率范围内搜索幅值最大的 bin
    2. 抛物线插值精炼频率:
         δ = 0.5 × (left - right) / (left - 2×center + right)
         实际频率 = (bin + δ) × 488Hz
         δ 限制在 [-0.5, 0.5]
    3. Hann 窗幅值补偿:
         真实幅值 = FFT幅值 × (1 + 0.71 × δ²)

  5.3 谐波搜索
  ──────────────────────────────────────────────────────────
    1. 扫描 orders 2~6:
       - 在期望频率 ±15% 窗口内找局部峰值
       - 计算窗口内幅值均值作为噪声基底
       - 本地 SNR = 峰值 / 均值
    2. 过滤条件:
       - SNR > 3.5× (2次谐波, 较严格, 避免基波泄漏)
       - SNR > 2.0× (3~6次谐波)
       - 峰值 > 基波 × 0.5%
       - 频率必须是基波的整数倍 ±15%
    3. 抛物线插值精炼频率 (同基波)
    4. 幅值 < 5mV 的谐波丢弃 (噪声门限)
    5. 按谐波次数升序排列, 取前两名
    6. 最终存储时按频率升序 (harmonic1 < harmonic2)

  5.4 真有效值计算
  ──────────────────────────────────────────────────────────
    rms_mv = sqrt(Vpp0² + Vpp1² + Vpp2²) / 1.4142136
    其中 Vpp = FFT_MAG_TO_VPP_MV(mag) = mag × 0.00483
    换算系数已通过基波 60mV 信号源校准

  5.5 峰峰值计算 (分量重建法)
  ──────────────────────────────────────────────────────────
    基波 + 谐波分量重建, 全部初始相位设 0:
      x̂(t) = Σ amp_i × sin(2π × f_i × t)
    在基波一个完整周期内均匀采样 4000 点
    upp_mv = (max - min) × 0.999

  5.6 IFFT 时域波形重建
  ──────────────────────────────────────────────────────────
    滤波数据 → 去直流 → FFT → IFFT → 干净时域波形
    输出存于 fft_input 数组, 供串口屏波形显示使用


六、Chebyshev 滤波器幅值补偿 (fft_analysis.c)
────────────────────────────────────────────────────────────────
  目的: 补偿硬件 7阶 Chebyshev LPF 对高频信号的衰减

  模型参数:
  - 截止频率 fc = 1.5 MHz
  - 通带纹波 = 0.5 dB
  - 阶数 N = 7
  - 通带插入损耗补偿系数 = 1.34 (实测校准)

  |H(f)| 计算:
    ε² = 10^(R_dB/10) - 1
    T_N(x) = Chebyshev 多项式 (递推法, 无查表)
    |H(f)| = 1 / sqrt(1 + ε² × T_N²(f/fc))

  补偿因子 = 1/|H(f)|
  - 上限: 100× (40dB, 防止阻带噪声被过度放大)
  - 应用到: 基波幅值 + 谐波1幅值 + 谐波2幅值

  调试标定方法:
  - 信号源输出 100kHz / 500kHz / 1MHz 正弦波
  - 对比串口屏读数与信号源设定值
  - 高频补偿不够 → 略减小 fc
  - 高频补偿过度 → 略增大 fc


七、模式管理 (problem3.c + 主循环)
────────────────────────────────────────────────────────────────

  7.1 题目一/二 模式
  ──────────────────────────────────────────────────────────
    - 继电器 PE5/PE6 = LOW (直连通路)
    - 无数字滤波
    - FFT 分析原始 ADC 数据 (stride=2, 无抗混叠保护)
    - 最大分析频率 500 kHz
    - 显示控件前缀 t1_xxx
    - 三视图: 频谱 + 波形 + 合成

  7.2 题目三 模式
  ──────────────────────────────────────────────────────────
    - 继电器 PE5/PE6 = HIGH (LPF 通路)
    - 硬件模拟 Chebyshev LPF (fc=1.5MHz)
    - 数字 64-tap FIR LPF (fc=750kHz) + 2:1 抽取
    - FFT 分析滤波后的数据 (stride=1, 无混叠噪声)
    - Chebyshev 幅值补偿
    - 最大分析频率 550 kHz
    - 显示控件前缀 t3_xxx
    - 四视图: IFFT波形 + 频谱 + 单周期 + 三周期

  7.3 切换机制
  ──────────────────────────────────────────────────────────
    - 中断回调设置 problem3_pending 标志 (不阻塞)
    - 主循环检测 pending 标志, 执行切换
    - 切换后丢弃前几帧采样 (继电器和滤波器稳定时间)
    - 初始视图: T3_VIEW_IFFT

  7.4 串口屏页面路由
  ──────────────────────────────────────────────────────────
    page7 → T3_VIEW_IFFT  (IFFT时域波形)
    page8 → T3_VIEW_SPEC  (频谱图)
    page4 → T3_VIEW_1T    (单周期合成)
    page5 → T3_VIEW_3T    (三周期合成)
    page6 → 暂停 (capture_on=0)


八、串口屏交互 (main.c HMI_RxHandler)
────────────────────────────────────────────────────────────────
  8.1 按钮命令
  ──────────────────────────────────────────────────────────
    控件ID 1 (bt0)   → START, 恢复采集
    控件ID 2 (bt1)   → PAUSE, 暂停采集
    控件ID 3 (b0)    → CLEAR, 清空所有波形
    控件ID 6 (b2)    → 切换题目三模式
    控件ID 13 (b6)   → X+, 水平缩放 +2
    控件ID 14 (b7)   → X-, 水平缩放 -2
    控件ID 15 (b8)   → Y+, 垂直缩放 +5
    控件ID 16 (b9)   → Y-, 垂直缩放 -5

  8.2 通信协议
  ──────────────────────────────────────────────────────────
    - 淘晶驰 TJC 协议, 115200bps
    - USART1 接收中断逐字节解析
    - 支持三种格式:
      1. 0x65 触摸帧 (7字节)
      2. ASCII 命令行 (以 \r\n 结尾)
      3. hex printh 裸字节序列 (4字节触发)
    - 页面查询: sendme 命令 → 0x66 响应 (5字节)
    - 启动时发送 bkcmd=0 禁止错误帧

  8.3 缩放机制
  ──────────────────────────────────────────────────────────
    - 缩放时暂停采集 (capture_on=0)
    - 修改 g_hzoom (X缩放) 或 g_scale (Y缩放)
    - zoom_dirty=1 → 主循环应用缩放并重画
    - 缩放后自动恢复采集 (capture_on=1)
    - 范围限制: hzoom [-20, 30], scale [-30, 30]


九、关键设计决策与优化
────────────────────────────────────────────────────────────────
  9.1 FFT 与 IFFT 同源数据 (题目三)
  ──────────────────────────────────────────────────────────
    问题: 最初 IFFT 用滤波数据, FFT 频域分析用原始数据
          → 波形干净但频率/幅值测量不准、不稳定
    解决: FFT 频域分析也改用 filtered_buffer
          → 测量值与波形显示完全一致
          → 无混叠噪声, 基波/谐波检测稳定

  9.2 抛物线三点插值精炼频谱峰值
  ──────────────────────────────────────────────────────────
    问题: FFT bin 分辨率 488Hz, 直接取峰值 bin 误差大
    解决: 利用峰值相邻 bin 的幅值做三点抛物线拟合
          频率精度可到几十 Hz 级别

  9.3 谐波检测的多层过滤
  ──────────────────────────────────────────────────────────
    层1: 局部 SNR 门限 (2次>3.5×, 其他>2.0×)
    层2: 幅值 > 基波 × 0.5%
    层3: 频率必须是基波整数倍 ±15%
    层4: 转换后幅值 < 5mV 丢弃
    → 有效区分真实谐波和噪声伪峰

  9.4 Chebyshev 多项式递推 (不查表)
  ──────────────────────────────────────────────────────────
    优点: 精度高, 无存储开销, 参数可调
    递推公式: T_k = 2x·T_{k-1} - T_{k-2}
    补偿因子实时计算, 上限 100× 防止阻带放大

  9.5 中断安全的状态传递
  ──────────────────────────────────────────────────────────
    中断只设置 volatile 标志 (problem3_pending / zoom_dirty 等)
    主循环检测并执行实际操作 (不阻塞、不延时)
    → 避免在中断中调用 HAL_Delay 等阻塞函数

  9.6 继电器切换过渡处理
  ──────────────────────────────────────────────────────────
    problem3_discard_frames 丢弃切换后的前几帧
    → 等待继电器触点稳定和模拟 LPF 建立
    → 避免瞬态数据污染分析结果

  9.7 ADC 数据去直流
  ──────────────────────────────────────────────────────────
    FFT 前: 计算采样均值, 每个点减去均值 → 消除 DC 分量
    FIR 滤波前: 减去 2048 (中心值) → 消除 DC 偏置
    → 防止 DC 分量泄漏到低频 bin, 影响基波检测


十、内存与性能
────────────────────────────────────────────────────────────────
  主要缓冲区:
    adc_buffer[8192]             16KB   (uint16_t)
    filtered_buffer[4096]        8KB    (uint16_t)
    fft_window[4096]             16KB   (float)
    fft_input[4096]              16KB   (float)
    fft_output[4096]             16KB   (float)
    fft_magnitude[2049]          8KB    (float)
    filter_coeffs[64]            256B   (const float)
    filter_state[64]             256B   (float, 栈上)

  关键性能:
    64-tap FIR (8192点输入)     ≈ 262k 次浮点乘加
    4096点实数FFT (CMSIS-DSP)   ≈ 22k 次浮点运算 (优化实现)
    DMA 传输 (8192点 @ 4MSPS)   ≈ 2ms / 帧
    单帧总处理时间               ≈ 3~5ms (满足实时性)


十一、调试与标定建议
────────────────────────────────────────────────────────────────
  1. 幅度校准:
     - 使用已知幅值的信号源 (如 100kHz/1.0Vpp)
     - 调整 FFT_MAG_TO_VPP_MV 换算系数
     - 当前值: 0.00483 (已通过 60mV 基波校准)

  2. Chebyshev 补偿校准:
     - 全频段扫频: 10kHz ~ 2MHz, 记录读数偏差
     - 微调 FilterComp_Init 的 fc/ripple_db/order 参数
     - 微调 g_passband_gain 插入损耗补偿

  3. FIR 滤波器验证:
     - 输入方波, 观察 IFFT 波形是否干净
     - 检查阻带衰减是否达到 -80dB 规格

  4. 频率精度验证:
     - 输入已知频率正弦波
     - 检查抛物线插值后的频率读数误差
     - 预期: < ±100Hz @ 100kHz
